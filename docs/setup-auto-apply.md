# Настройка авто-откликов и доступа с телефона

Краткий практический чеклист: как корректно настроить бота, чтобы откликаться по нужным критериям и удобно управлять с телефона.

## 1. Что искать (поисковые URL)

Бот откликается на вакансии из поисковых ссылок hh.ru. Настраиваются на карточке аккаунта или в глобальном пуле (вкладка **Кампании** → URL).

1. Открой hh.ru, настрой поиск как обычно (запрос, регион, опыт, формат) и **скопируй ссылку из адресной строки**.
2. Добавь её в список URL. Можно несколько — по одной на каждое направление (например «Python remote», «DevOps Москва»).
3. Совет: в запросе уже задавай регион/формат — это сужает выдачу на стороне hh.ru.

**Критерий, по которому нашлась вакансия, сохраняется** и виден в истории (бейдж и фильтр «Все критерии»). Текст бейджа берётся из параметра `text=` ссылки.

## 2. Фильтры (вкладка Настройки)

| Настройка | Зачем | Рекомендация для старта |
|-----------|-------|--------------------------|
| **Мин. зарплата** (`min_salary`) | Отсечь низкооплачиваемое | 0, потом поднять под себя |
| **Формат работы** | Удалёнка / офис / гибрид | Отметь нужные (пусто = все) |
| **Стоп-слова в заголовке** (чёрный список) | Не откликаться на «Senior», «1С», «продажи» и т.п. | Заполни под свои нежелательные слова |
| **Белый список заголовков** | Откликаться ТОЛЬКО на вакансии с этими словами | Оставь пустым, если не уверен — строгий фильтр |
| **Дневной лимит** (`daily_apply_limit`) | Не словить лимит hh.ru | 100–150/день на аккаунт |
| **Размер пачки** (`batch_responses`) | Сколько откликов за раз | 3 (дефолт) — не повышай без нужды |
| **Задержка** (`response_delay`) | Пауза между откликами | 1–3 сек |

> ⚠️ **Стоп-слова работают по заголовку вакансии.** Белый список строгий: если у вакансии не распарсилось название — она будет отсеяна. Поэтому белый список включай осознанно.

> ⚠️ Слишком большие пачки/частые отклики и нулевые задержки повышают риск временного лимита со стороны hh.ru. Начни консервативно.

## 3. Где смотреть отклики

Вкладка **История** → «Отклики»:
- На телефоне — лента карточек (название, компания, зарплата, **критерий**, дата).
- Фильтры: по аккаунту, по **критерию** (поисковому запросу), поиск по тексту.
- Кнопка «Экспорт CSV».

## 4. Доступ с телефона (пароль + HTTPS)

Доступ защищён паролем и работает по HTTPS (nginx, порт **8443**).

### Шаги
1. Скопируй `.env.example` → `.env` и задай:
   ```
   DASHBOARD_PASSWORD=<твой_пароль>
   SESSION_SECRET=<длинная_случайная_строка>
   ```
   Сгенерировать секрет: `python3 -c "import secrets; print(secrets.token_hex(32))"`.
2. Запусти: `docker-compose up -d`.
3. Зайди с телефона: `https://<IP-сервера>:8443`.
   - Браузер один раз предупредит о самоподписанном сертификате — нажми «Всё равно открыть».
   - Введи пароль. Сессия живёт 14 дней.

> Если `DASHBOARD_PASSWORD` пустой — авторизация **выключена** (открытый доступ). Для доступа из интернета пароль обязателен.

> `.env` уже в `.gitignore` — пароль в репозиторий не попадёт.

### Локальный запуск (без Docker)
`python web_app.py` тоже читает `.env` (порт 8000, без HTTPS). Для интернета используй Docker-вариант с nginx.

### Опционально: убрать предупреждение о сертификате
Если есть аккаунт Cloudflare, можно поднять **Cloudflare Tunnel** и получить валидный сертификат и адрес без предупреждений браузера. Правок кода не требует.

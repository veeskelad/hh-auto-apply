# Requirements

- Provide a usable FastAPI dashboard for hh.ru automation.
- Keep existing bot workflows intact: account connection, search/apply, history, tests, database, HH status, resume views, campaigns, LLM replies, and settings.
- UI changes must preserve current IDs and JS hooks unless explicitly changed together with their callers.
- The dashboard must not have incoherent overlap, clipped controls, or unusable narrow columns on desktop, tablet, or mobile.
